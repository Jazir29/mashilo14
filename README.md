# Mashilo — Tarjeta de cumpleaños para Máximo

Sitio estático con la historia visual que se abre al escanear el QR de la tarjeta física.

## Estructura

- `docs/` — sitio público (lo que GitHub Pages sirve)
  - `index.html`, `styles.css`, `script.js`
  - `config.js` — textos editables sin tocar código
  - `assets/` — fotos y videos
- `tarjeta/` — tarjeta A4 imprimible con QR
